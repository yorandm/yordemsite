# Wiskunde 1 - klaswebsite

Open `index.html` rechtstreeks in een moderne browser. Er is geen installatie,
login, Node of internetverbinding nodig.

## Aanpassen

- Sitenaam en hoofdstukken: `js/config.js`
- Kleuren en vormgeving: `css/style.css`
- Inhoud hoofdstuk 1: `hoofdstukken/getallen-en-verzamelingen.html`
- Afdrukbare poster: `posters/getallen-en-verzamelingen.html`

Zet bij een hoofdstuk `visible: true` om het in de navigatie te tonen. Verborgen
hoofdstukken verschijnen niet in de website. Dit is geen beveiliging: bestanden
die op een publieke hostingdienst staan, kunnen met hun rechtstreekse URL nog
steeds worden geopend.
