Hoofdstuk 1 · samenvatting

Getallen en verzamelingen

Elementen ordenen, voorstellen en combineren.

1. Verzameling en opsomming

Bevat verschillende elementen die een geheel vormen.

A = {1, 2, 3, 4}

Noteer elk verschillend element één keer.

Opsomming: alle verschillende elementen tussen accolades, gescheiden door komma’s.

Getallen noteer je van klein naar groot.

letters van “ananas” → A = {a, n, s}

Leeg: ∅ of { }

3. Bewerkingen zichtbaar gemaakt

A B 1 2 3 4 5

A ∩ B = {3, 4} · in beide

A ∪ B = {1, 2, 3, 4, 5} · in minstens één

A ∖ B = {1, 2} · wel in A, niet in B

B ∖ A = {5} · wel in B, niet in A

4. Taal ↔ symbolen

3 ∈ A
3 is een element van A.

5 ∉ A
5 is geen element van A.

{3} ⊂ A
De verzameling met 3 is een deelverzameling van A.

2. Deelverzameling

A is een deelverzameling van B als elk element van A ook een element van B is.

A zit dus volledig in B.

A ⊂ B

5. Let op

∈ gebruik je bij een element.

⊂ gebruik je bij een verzameling.

De volgorde telt:

A ∖ B ≠ B ∖ A

!
Edutron onthoudt: ∩ = in beide · ∪ = in minstens één · ∖ = wel in de eerste, niet in de tweede.
